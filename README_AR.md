# Salam AI PWA — نسخة الأيقونة والاسم المخصصين

هذه الحزمة تجعل تثبيت التطبيق من GitHub Pages باسم **Salam AI** وبالشعار المخصص، مع عرض تطبيق Streamlit داخل الصفحة.

## طريقة التحديث
1. افتح مستودع GitHub: `MomenSala7/salam-ai-pwa`.
2. ارفع كل الملفات الموجودة داخل هذا المجلد إلى جذر المستودع، مع استبدال الملفات القديمة عند الطلب.
3. تأكد من أن GitHub Pages مفعّل من الفرع `main` والمجلد `/ (root)`.
4. افتح `https://momensala7.github.io/salam-ai-pwa/` في Chrome على Android.
5. احذف اختصار Streamlit القديم من الشاشة الرئيسية.
6. من قائمة Chrome اختر **Install app / تثبيت التطبيق**. لو ظهر **Add to Home screen / إضافة إلى الشاشة الرئيسية** اختره، ثم تأكد أن الاسم هو Salam AI.

**مهم:** لا تثبّت `salam-uae.streamlit.app` مباشرة؛ التثبيت يجب أن يتم من رابط GitHub Pages أعلاه حتى يستخدم الهاتف manifest والشعار المخصصين.
